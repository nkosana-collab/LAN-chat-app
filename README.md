# LAN-chat-app
A headless program that allows devices on the same network to communicate with each other through sockets. 

## Features 
- Send and receive text through terminal.
- Multiway user interactions.
- lightweight design.

## Tech Stack
- Java Sockets.
- Threads and ExecutorService for threadpool.
- JSON Serialization.

## Installation/Setup
- Clone the repo:
- SSH - [git clone git@github.com:nkosana-collab/LAN-chat-app.git]
- HTTPS - [https://github.com/nkosana-collab/LAN-chat-app.git]
- The host can run the Server class and the guests can run the Client class on the machine.
